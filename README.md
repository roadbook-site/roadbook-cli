# Roadbook Project

This repository contains the Roadbook project, which is structured as follows:

- `client/`: The CLI application and local runtime for Roadbook.
- `server/`: The server-side components (Work in Progress).
- `docs/`: Project documentation and architecture specifications.

## Getting Started

### Client

Navigate to the `client` directory to work with the CLI.

```bash
cd client
pip install -e .
```

For more details, see the [Client README](client/README.md).
