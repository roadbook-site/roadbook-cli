# Roadbook 国际化 (i18n) 设计与规范文档

本文档详细说明了 Roadbook CLI 与前端可视化编辑器的国际化（i18n）架构、语言检测优先级以及跨平台兼容性。

## 1. 语言优先级机制

系统在决定最终呈现的语言时，遵循以下**由高到低**的优先级顺序：

1. **用户显式配置 (最高优先级)**
   - 读取用户 Profile 目录下的配置文件：`~/.roadbook/.core/config.yaml`
   - 配置项：`core.language`
   - 如果该值被明确设置为 `zh` 或 `en`，系统将无条件使用该语言。
   - 如果该值为 `auto`（默认值）或未配置，系统将进入下一步自动检测流程。

2. **系统环境变量**
   - 系统会依次检查以下标准的 POSIX 国际化环境变量（这是 Linux/Unix 生态中约定俗成的 GNU gettext 标准）：
     1. `LANGUAGE`：最高优先级的环境变量，通常用于指定首选语言的回退列表（如 `zh_CN:zh:en`）。
     2. `LC_ALL`：强制覆盖所有本地化设置的宏观变量。
     3. `LC_MESSAGES`：专门用于控制软件提示信息（如报错、日志）的语言变量。
     4. `LANG`：基础环境变量，当上述变量未设置时作为默认的回退配置。
   - 一旦发现其中包含 `zh`（如 `zh_CN.UTF-8`），则判定为中文；否则默认英文。这在 Linux/macOS 环境以及 CI/CD 自动化流水线中非常有效。

3. **操作系统底层 API 检测**
   - 如果环境变量未提供有效信息，系统会调用操作系统底层接口来获取系统 UI 语言：
     - **Windows**: 调用 `ctypes.windll.kernel32.GetUserDefaultUILanguage()` 获取 Language ID（例如 `0x0804` 代表简体中文）。
     - **macOS / Linux**: 调用 Python 标准库 `locale.getlocale()` 获取操作系统的区域设置。

4. **默认兜底 (最低优先级)**
   - 如果以上所有步骤均未成功检测到语言，系统将默认回退到英文 (`en`)。

## 2. 跨平台兼容性

Roadbook 的国际化检测机制是 **完全跨平台兼容** 的，针对不同操作系统做了底层适配：

- **Windows**:
  - Windows 环境下 `locale.getlocale()` 有时无法准确反映系统真实的显示语言（尤其是用户在控制面板更改了语言但未更改区域格式时）。
  - 因此，我们专门引入了 `ctypes` 调用 Windows 的 Win32 API (`GetUserDefaultUILanguage`)，确保在 Windows 10/11 上能够 100% 准确获取用户的真实界面语言。
- **macOS / Linux (POSIX)**:
  - 优先依赖环境变量（`LANG`, `LC_ALL` 等），这符合 POSIX 系统的标准规范。
  - 作为补充，`locale.getlocale()` 能够完美读取 Unix 系统的本地化设置。

## 3. 架构设计与前后端联动

Roadbook 的 i18n 采用**“后端主导，前端自适应”**的架构设计：

1. **命令行端 (CLI)**：
   - 核心实现在 `src/roadbook/core/i18n.py`。
   - 提供 `t(key, **kwargs)` 函数供其他模块（如 `initialize.py`）调用。
   - 所有的翻译字符串都集中管理在 `TRANSLATIONS` 字典中。

2. **前端编辑器端 (Web UI)**：
   - 本地启动的 FastAPI Server (`app.py`) 会在 `/api/config` 接口中注入后端计算得出的 `language`。
   - 前端 (`index.html`) 在初始化时：
     - 首先检查浏览器的 `localStorage` 中是否有用户手动切换的语言缓存。
     - 如果没有，则直接读取 `/api/config` 返回的 CLI 语言。
     - 这样保证了“CLI 终端打印的语言”和“自动打开的浏览器界面的语言”保持绝对的一致。

## 4. 如何添加/修改翻译

1. **修改 CLI 提示词**：
   - 打开 `src/roadbook/core/i18n.py`。
   - 在 `TRANSLATIONS` 字典中，分别为 `en` 和 `zh` 键添加相同的 Key 和对应的翻译文本。
   - 支持 Python 的 `str.format()` 变量插值，例如：`"init_success": "成功初始化 {name}"`。

2. **修改 Web 前端提示词**：
   - 打开 `src/roadbook/web/static/index.html`。
   - 找到 `<script>` 标签内的 `translations` 对象，按照相同的方式添加或修改 Key。
